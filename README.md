# Pithagoras

A local AI agent system with voice control, a macOS menu-bar app, and hardware-aware model selection.
Built on [Pi](https://pi.dev) — a web portal for coding agents.

## What Is Pithagoras?

Pithagoras is a **web-based portal** for managing AI coding agents. It gives you:

- **A web interface** to chat with and control coding agents
- **Voice mode** — talk to your agent, it responds in your voice
- **A macOS menu-bar app** — one-click control of all services
- **Hardware-aware setup** — auto-selects the best model for your laptop
- **Local AI** — runs on your machine via [Ollama](https://ollama.com), no cloud required

## Quick Start

```bash
git clone https://github.com/ghpontapalli/my-assistant.git
cd my-assistant
npm install
```

### 1. Set your git identity

Commits require a name and email. If you haven't set one yet:

```bash
git config user.name "Your Name"
git config user.email "you@example.com"
```

Or set it globally for all your repos:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

### 2. Create your `.env`

The portal reads configuration from `.env`. Copy the example and adjust:

```bash
cp .env.example .env
```

Edit `.env` to set your own `PORTAL_SECRET` and the directory your projects live in (`WORKSPACES_DIR`). See `.env.example` for all options.

### 3. Run the setup wizard

```bash
npm run setup
```

This detects your hardware and creates `config.json` with the right model and context limit for your machine. Skip it if you already have a `config.json`.

### 4. Build & start

```bash
npm run build
npm run start:bg
```

The build compiles TypeScript to `dist/`. The `start:bg` command loads your `.env`, starts Ollama and OmniRoute (if configured), and launches the server in the background.

Open the URL that prints. A password is generated and saved with the data on the first start; you get a link instead of a printed password once you have set one.

> **Tip:** To start just the server without Ollama/OmniRoute (for development), use `npm run dev:server`.
>
> To stop everything: `npm run stop`.

## Hardware-Based Model Selection

The setup wizard (`npm run setup`) auto-detects your hardware and suggests a model:

| Your RAM | Recommended Model | Context | Use Case |
|---|---|---|---|
| < 8 GB | `tinyllama:1.1b` | 2K | Quick tasks, low-end devices |
| 8 GB | `phi3:mini` or `llama3:8b-q4` | 4K–8K | General coding, chat |
| 16 GB | `llama3:8b` or `mistral:7b` | 8K | Complex coding, reasoning |
| 32 GB+ | `qwen2:7b` or larger | 32K+ | Long context, multilingual |

**Why model size matters:**
- **tinyllama (1.1B)**: Fastest, runs on 2GB RAM. Good for quick questions but limited reasoning.
- **phi3 (3.8B)**: Balanced. Good coding ability, fits 8GB RAM. The default recommendation.
- **llama3 (8B)**: Powerful. Complex multi-step reasoning, long context. Needs 16GB+ for full speed.
- **qwen2 (7B)**: Multilingual, huge 32K context. Great for non-English tasks.

### Context Length

Each model has a **context window** — how many tokens it can "remember" in one conversation:

| Model | Context | Roughly |
|---|---|---|
| tinyllama | 2,048 | ~1,500 words |
| phi3:mini | 4,096 | ~3,000 words |
| llama3:8b | 8,192 | ~6,000 words |
| qwen2:7b | 32,768 | ~24,000 words |

Larger context = more memory. The wizard sets this automatically in `config.json`.

## Ollama Integration

Pithagoras uses [Ollama](https://ollama.com) for local LLM inference.

### Install Ollama
```bash
# macOS
brew install ollama

# Linux
curl -fsSL https://ollama.com/install.sh | sh
```

### Pull a Model
```bash
ollama pull phi3:mini
```

## macOS Menu-Bar Control

A native menu-bar app (`PithagorasControl.app`) gives you one-click control:

- **Portal** — start/stop the web server
- **Ollama** — start/stop the local LLM
- **OmniRoute** — start/stop the router
- **Voice** — toggle voice mode on/off
- **Docker** — start/stop Docker services
- **Logout** — stop everything

Install:
```bash
npm run autostart    # sets up macOS launchd
npm start:bg          # starts all services in background
```

```bash

```

## Voice Mode

- **VAD (Voice Activity Detection)**: Silero V5, runs in-browser
- **STT (Speech-to-Text)**: Whisper, runs locally
- **TTS (Text-to-Speech)**: audiocpp, runs locally
- **Style**: Witty, concise, 1-3 sentences, no markdown, proactive follow-ups

## Requirements

## FAQ

**"Do I need a cloud API?"**
No. Pithagoras runs entirely locally via Ollama. No internet required after setup.

**"Which model should I pick?"**
Run `npm run setup` — it auto-selects based on your RAM.

**"Can I change my model later?"**
Yes. Run `npm run setup` again to re-select.

**"Is Pithagoras multi-tenant?"**
No. Single password, built for private/Tailscale use.

**"Is it a sandbox?"**
By default, no. The host executor runs pi as a child process with your permissions. Use container mode for isolation.
